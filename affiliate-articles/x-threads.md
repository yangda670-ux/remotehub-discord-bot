## A-2/7

```
①仕組み

アフィリエイトは「成果報酬型」の広告です。

広告主 → ASP(仲介会社)→ 発信者 → 読者

読者が紹介リンクから購入・申し込みをし、成果が確認されると、ASPを通じて発信者に報酬が支払われます。
```

・フォロワーがなくても取り組める場合がある
・一般的に広告費がかかる場合がある
・赤字になる可能性もある

【画像:x-04.png】

## B-2/7

```
①期待値を整える

アフィリエイトは成果報酬型。成果が出なければ、報酬はありません。

結果には個人差があり、収益は保証されないもの。

「まず仕組みを知る」を、最初のゴールにすると焦らずに進めやすくなります。
```

## B-3/7

```
②お金の上限を決める

一般的にかかる可能性があるのは、
・学ぶための費用(本、講座など)
・発信のための費用
・広告費(広告アフィの場合)

「生活費には手をつけない」など、自分なりのルールを先に決めておきましょう。
```

## B-4/7

```
③用語は、よく出るものから

・ASP:広告主と発信者の仲介
・LP:最初にたどり着く申し込みページ
・CPC:1クリックあたりの広告費
・CVR:成約率

全部を一度に覚える必要はありません。出てきたら、その場でメモ。
```

## B-5/7

```
④スキマ時間で学ぶ

・通勤中:動画で「見る」
・昼休み:用語や疑問を「書く」
・夜の15分:メモを「振り返る」

1回の目標は小さく。「用語を2つ覚える」くらいから始めてみてください。
```

## B-6/7

```
⑤情報を見極める

□ 結果を約束する強い表現がないか
□ 誰が、何をもとに言っているか
□ 金額と内容がはっきりしているか
□ その場で決めず、持ち帰れるか

自分で納得してから選ぶことが、いちばんの自己防衛です。
```
