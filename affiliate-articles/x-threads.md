## A-2/7

```
①仕組み

アフィリエイトは「成果報酬型」の広告です。

広告主 → ASP(仲介会社)→ 発信者 → 読者

読者が紹介リンクから購入・申し込みをし、成果が確認されると、ASPを通じて発信者に報酬が支払われます。
```

```
②広告アフィとは

・フォロワーがなくても取り組める場合がある
・一般的に広告費がかかる場合がある
・赤字になる可能性もある
```

# スレッドB:学び始める前に知っておきたい5つのこと(note記事より)

②お金の上限を決める

```

【画像:x-04.png】

## B-2/7

```
①期待値を整える

アフィリエイトは成果報酬型。成果が出なければ、報酬はありません。

結果には個人差があり、収益は保証されないもの。

「まず仕組みを知る」を、最初のゴールにすると焦らずに進めやすくなります。
```

## B-3/7

```
②お金の上限を決める

一般的にかかる可能性があるのは、
・学ぶための費用(本、講座など)
・発信のための費用
・広告費(広告アフィの場合)

「生活費には手をつけない」など、自分なりのルールを先に決めておきましょう。
```

## B-4/7

```
③用語は、よく出るものから

・ASP:広告主と発信者の仲介
・LP:最初にたどり着く申し込みページ
・CPC:1クリックあたりの広告費
・CVR:成約率

全部を一度に覚える必要はありません。出てきたら、その場でメモ。
```

## B-5/7

```
④スキマ時間で学ぶ

・通勤中:動画で「見る」
・昼休み:用語や疑問を「書く」
・夜の15分:メモを「振り返る」

1回の目標は小さく。「用語を2つ覚える」くらいから始めてみてください。
```

## B-6/7

```
⑤情報を見極める

□ 結果を約束する強い表現がないか
□ 誰が、何をもとに言っているか
□ 金額と内容がはっきりしているか
□ その場で決めず、持ち帰れるか

自分で納得してから選ぶことが、いちばんの自己防衛です。
```

```

結果には個人差があり、登録後に商品の案内がある場合があります。

# スレッドC:無料の動画セミナーを活かすコツ(Ameba 2記事目より)

## C-1/8

```
無料の動画セミナーを「見て終わり」にしないコツを、順番に整理します。

①良いところ
②気をつけたいところ
③見る前の準備
④見ている間のメモ
⑤見たあとの整理
⑥有料の案内を受けたとき

本業の合間に学びたい方へ。
#PR
```

【画像:diagram-06.png】

## C-2/8

```
①良いところ

・費用をかけずに、全体像をつかめる
・講師の考え方や、説明の分かりやすさを確かめられる
・自分のペースで、止めたり見返したりできる

「全体像をつかむ場」と考えると、活用しやすくなります。
```

## C-3/8

```
②気をつけたいところ

・登録後に、商品の案内がある場合がある
・動画だけでは、細かい疑問が残ることもある
・内容は講師の考え方によるので、ほかの情報とも比べる

知っておくだけで、落ち着いて向き合えます。
```

【画像:diagram-05.png】

## C-4/8

```
③見る前の準備

・見る目的を1つ決める(例:仕組みを知りたい)
・約30分の時間を確保する
・メモを用意する(スマホのメモで十分)

目的が決まると、聞くべきポイントがはっきりします。
```

## C-5/8

```
④見ている間のメモ

・全部は書かない。気になった点だけ
・知らない用語も、そのまま記録
・事実と意見を分けて書く
・費用やリスクの話があったかもメモ

あとで比べるときに役立ちます。
```

## C-6/8

```
⑤見たあとの整理(5分でOK)

□ 目的に、答えは見つかったか
□ 分からなかったことは何か
□ 時間とお金は、どのくらいかかりそうか
□ 生活に無理なく取り入れられそうか

答えが出ない点は、本などとも比べてみてください。
```

## C-7/8

```
⑥有料の案内を受けたとき

大切なのは、その場で決めないこと。

・内容は具体的か
・金額と支払い方法は明確か
・返金などの条件はあるか
・ほかの選択肢と比べたか

合わないと感じたら、見送るのも一つの選択です。
```
