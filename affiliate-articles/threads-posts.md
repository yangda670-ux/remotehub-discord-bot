# Threads用投稿

- Threadsは、Xより長く書け(500字まで)、会話のような、やわらかい文が読まれやすい傾向があります。
- セミナー名を出す投稿(Threads 1)だけ、末尾に「#PR」を入れます。トピック(タグ)は1つだけ付けます。
- 2本は、日を分けて投稿します。

## Threads 1(記事の紹介・まとめ型)

```
無料の動画セミナー、見て終わりになっていませんか?

本業の合間に学ぼうとすると、せっかく見ても「何が分かったんだっけ?」となりがち。そこで、約30分の動画を活かすコツをブログに整理しました。

▼見る前
目的を1つ決める/30分を確保する/メモを用意する

▼見ている間
気になった点だけ書く/知らない用語もそのまま記録/事実と意見を分ける

▼見たあと
5分だけ、メモを整理する

それと、無料セミナーのあとに有料の案内が届くこともあります。その場で決めず、内容と金額を確かめて、ほかと比べてから考えるのがおすすめです。

記事の後半では、無料動画セミナー「光速アフィリエイト」の概要も、LPに書かれた範囲で紹介しています。結果には個人差があり、登録後に商品の案内がある場合があります。

```
