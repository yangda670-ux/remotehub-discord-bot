# 無料動画セミナー紹介記事(光速アフィリエイト)一式

## 専用リンクの差し替え方法

各ファイルの冒頭、1か所だけを書き換えます。

| ファイル | 定義している場所 | 記事内での使い方 |
|---|---|---|
| ameba-01.md / note-01.md | `[seminar]: https://...`(Markdownの参照リンク) | `[テキスト][seminar]` |
| x-posts.md | `SEMINAR_URL: https://...` | `{SEMINAR_URL}` |

書き換えたあと `python3 build.py` を実行すると、URLを展開した貼り付け用のファイルが `dist/` に出力されます(X投稿の文字数チェックも行います)。

## ファイル一覧

| ファイル | 内容 |
|---|---|
| ameba-01.md | Amebaブログ用記事(指定の9章構成) |

| x-posts.md | X用投稿 5本(各140字以内、URLは23字換算) |
| dist/ | リンク展開済みの貼り付け用ファイル(build.py で生成) |

| dist/ameba-01-preview.html | 上記HTMLの、画像入りプレビュー |
| images/*.png | 記事用画像 11枚 |
| image-src/render.js | 画像のデザイン元(HTML/CSS/SVG → PNG)。`node image-src/render.js` で再生成 |

## Amebaへの貼り付け手順(HTML)

1. Amebaの画像フォルダに、Ameba用の画像(ameba-01-header / diagram-01 / diagram-02 / steps-01 / button-01)をアップロードします。
2. `dist/ameba-01.html` を開き、`<!-- ▼画像:… -->` の直後にある `src="images/…"` を、アップロードした画像のURLに差し替えます。
3. 記事タイトルは、ファイル1行目のコメントにある文言を、Amebaのタイトル欄に入れます。
4. エディタの「HTML表示」タブに切り替え、残りの内容をすべて貼り付けます。
