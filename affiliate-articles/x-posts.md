## 追加6(用語解説:CPC)

```
【用語メモ】CPCってなに?

「Cost Per Click」の略で、広告が1回クリックされるごとにかかる費用のことです。

広告アフィでは、このCPCと、申し込みの割合(CVR)をセットで見るのが基本。

数字の意味から、少しずつ覚えていきましょう。
#PR
```

## 追加7(用語解説:CVR)

```
【用語メモ】CVRってなに?

「成約率」のこと。ページを見た人のうち、申し込みなどの成果につながった人の割合です。

例:100人が見て、2人が申し込み → CVRは2%

広告費を考えるときに欠かせない数字です。
#PR
```

## 追加8(用語解説:LP)

```
【用語メモ】LPってなに?

「ランディングページ」の略で、広告やリンクから最初にたどり着くページのことです。

申し込みの前に、LPの内容や注意書き、運営会社の情報を読む習慣をつけておくと、落ち着いて判断できます。
#PR
```

## 追加9(よくある勘違い:成果の確定)

```
【よくある勘違い】
「紹介したら、その場で報酬が確定する」

一般的に、成果は広告主の確認を経て確定します。確認の結果、対象外になることもあります。

仕組みを知っておくと、焦らずに続けやすくなります。
#PR
```

内容と金額を確かめ、納得できたときだけ検討しましょう。断るのも、一つの選択です。

## 追加11(学び方の比較:独学と講座)

```
独学と講座、どっちがいい?

・独学:費用を抑えやすい/情報の取捨選択が必要
・講座:質問できる/費用がかかる場合がある

どちらにも良さがあります。まずは無料の情報で全体像をつかみ、必要に応じて考えるのも一つの方法です。
#PR
```
