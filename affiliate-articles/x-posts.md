# 追加ストック(2週間の検証用。反応の良い型を増やす)

## 追加6(用語解説:CPC)

```
【用語メモ】CPCってなに?

「Cost Per Click」の略で、広告が1回クリックされるごとにかかる費用のことです。

広告アフィでは、このCPCと、申し込みの割合(CVR)をセットで見るのが基本。

数字の意味から、少しずつ覚えていきましょう。
#PR
```

## 追加7(用語解説:CVR)

```
【用語メモ】CVRってなに?

「成約率」のこと。ページを見た人のうち、申し込みなどの成果につながった人の割合です。

例:100人が見て、2人が申し込み → CVRは2%

広告費を考えるときに欠かせない数字です。
#PR
```

## 追加8(用語解説:LP)

```
【用語メモ】LPってなに?

「ランディングページ」の略で、広告やリンクから最初にたどり着くページのことです。

申し込みの前に、LPの内容や注意書き、運営会社の情報を読む習慣をつけておくと、落ち着いて判断できます。
#PR
```

## 追加9(よくある勘違い:成果の確定)

```
【よくある勘違い】
「紹介したら、その場で報酬が確定する」

一般的に、成果は広告主の確認を経て確定します。確認の結果、対象外になることもあります。

仕組みを知っておくと、焦らずに続けやすくなります。
#PR
```

## 追加10(よくある勘違い:無料セミナー)

```
【よくある勘違い】
「無料セミナーなら、そのあと何の案内もない」

無料のセミナーでも、登録後に有料の講座などの案内がある場合があります。

内容と金額を確かめ、納得できたときだけ検討しましょう。断るのも、一つの選択です。
#PR
```

## 追加11(学び方の比較:独学と講座)

```
独学と講座、どっちがいい?

・独学:費用を抑えやすい/情報の取捨選択が必要
・講座:質問できる/費用がかかる場合がある

どちらにも良さがあります。まずは無料の情報で全体像をつかみ、必要に応じて考えるのも一つの方法です。
#PR
```

```
【情報を見極めるチェックリスト】

□ 結果を約束する強い表現がないか
□ 誰が、何をもとに言っているか
□ 金額と内容がはっきりしているか
□ その場で決めず、持ち帰れるか
□ 規約に反していないか

迷ったら、一度立ち止まりましょう。
#PR
```

・紹介してよい場所(SNS、ブログなど)

広告媒体とASPの、両方の規約を見るのがポイントです。

## 追加15(用語解説:成果報酬型)

```
【用語メモ】成果報酬型ってなに?

広告が表示されただけでは報酬にならず、購入や申し込みなどの「成果」が確認されたときに報酬が支払われる形のことです。

アフィリエイトの基本になる考え方なので、最初に押さえておきましょう。
#PR
```

## 追加16(用語解説:否認)

```
【用語メモ】否認ってなに?

申し込みなどがあっても、広告主の確認の結果、成果の対象外になることです。

条件は案件ごとに決まっています。紹介する前に、ASPの案件ページで条件を確認しておきましょう。
#PR
```
